## 📖 About

HARSHII'S Mehndi Art is a modern e-commerce and booking platform designed for professional mehndi artists and customers.

The platform allows customers to:

- 🛍 Purchase premium mehndi products
- 📅 Book professional mehndi services
- ❤️ Save favourite products
- 🛒 Manage shopping cart
- 📦 Track orders
- 👤 Create personal accounts
- 📱 Browse a responsive and elegant gallery

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/harshi-mehndi.git
```

Move inside the project

```bash
cd harshi-mehndi
```

Install dependencies

```bash
npm install
```

Create environment variables

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL

VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

Run locally

```bash
npm run dev
```

Build

```bash
npm run build
```

Preview

```bash
npm run preview
```
